\section{Master Comparison Tables and Data Schema}
\label{app:master-comparison}

The master comparison should be maintained as a single controlled dataset. The
body tables and specialist appendix views are outputs from that record. This avoids
different values becoming established for the same instrument in different parts
of the report.

\item Apply detector-family colour coding to the %technology cell in both canonical tables.
\item Resolve whether MATCH and the separately described Chang'e-7 energetic-particle detector are one payload, related subsystems or separate activities.
\item Standardise units and state whether energy ranges are incident, deposited or reconstructed energies.
\item Complete mass, power, dimensions, field of view, geometric factor and interface fields without inference.
\item Generate mass--power, energy-coverage and development-timeline figures directly from the controlled dataset.
\item Add source notes or citations at row level where values come from different configurations.
\end{enumerate}
